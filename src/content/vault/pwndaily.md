[PwnDaily](/labs/pwndaily/) 是一个每日自动生成的 Pwn 练习卷系统。每天 22:01 自动生成一份涵盖选择、填空、问答的试卷，附参考答案与详细讲解，帮助你持续巩固 Pwn 基础知识。

## 立即开始

**[进入 PwnDaily →](/labs/pwndaily/)**

## 特性

- **每日自动出题**：每天 22:01 生成新试卷，覆盖不同知识点，不重复
- **多种题型**：选择题、填空题、问答题（写 exp、命令、思路）
- **难度梯度**：基础题 → 中等题 → 高难题，约 30 分钟完成
- **答案与讲解**：提交后展示参考答案与逐题讲解
- **答题记录**：自动保存到本地，支持查看历史作答与成绩
- **导出/导入**：可导出答题记录备份，换设备时导入迁移

## 使用方法

1. 进入页面后自动加载当日试卷
2. 逐题作答（选择题点击选项，填空题输入答案，问答题写入 exp/思路并对照参考答案自评）
3. 点击「提交并查看答案」查看得分与逐题讲解
4. 在「历史记录」中查看往期试卷和自己的作答

## 设计说明

- 所有答题记录仅保存在当前浏览器的 localStorage 中，不上传任何服务器
- 问答题为开放式作答，由你对照参考答案自行判定对错，更贴近真实训练
- 试卷为纯静态 JSON，部署在 GitHub Pages，任何人都可以访问学习
