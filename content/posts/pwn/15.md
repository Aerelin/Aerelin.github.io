## 1. 堆简介

### 1.1 什么是堆

在程序运行过程中，**堆（Heap）** 可以提供动态分配的内存，允许程序申请大小未知的内存。堆其实就是程序虚拟地址空间的一块连续的线性区域，它由**低地址向高地址方向增长**。我们一般称管理堆的那部分程序为**堆管理器**。

#### 程序虚拟地址空间布局

```
高地址
┌─────────────────────┐
│    Kernel Space     │  用户代码无法读写这些地址，
│                     │  否则会导致 Segmentation Fault
├─────────────────────┤
│       Stack         │  随机栈偏移
│   (grow down)       │  RLIMIT_STACK (e.g., 8MB)
├─────────────────────┤
│ Memory Mapping      │  随机映射偏移
│ Segment             │
│ (mmap 区域)         │  文件映射（包括动态链接库）和匿名映射
│                     │  例如: /lib/libc.so
├─────────────────────┤
│        Heap         │  program break (brk)
│   (grow up)         │  start_brk
├─────────────────────┤
│     BSS Segment     │  随机 brk 偏移
│  (未初始化静态变量)   │  例如: static char *varName;
├─────────────────────┤
│    Data Segment     │  end_data
│  (已初始化静态变量)   │  例如: static char *quote = "That's one prototype";
├─────────────────────┤
│    Text Segment     │  start_data
│      (.text)        │  存储程序二进制镜像 (e.g., /bin/gzexe)
└─────────────────────┘
低地址
```

#### 堆管理器示例

```c
int *a = malloc(0x10);
int *b = malloc(0x20);
int *c = malloc(0x100);
```

### 1.2 堆管理器的职责

堆管理器处于**用户程序与内核中间**，主要做以下工作：

1. **响应内存申请请求**：向操作系统申请内存，然后将其返回给用户程序。同时，为了保持内存管理的高效性，内核一般都会预先分配很大的一块连续的内存，然后让堆管理器通过某种算法管理这块内存。只有当出现了堆空间不足的情况，堆管理器才会再次与操作系统进行交互。

2. **管理用户释放的内存**：一般来说，用户释放的内存并不是直接返还给操作系统的，而是由堆管理器进行管理。这些释放的内存可以来响应用户新申请的内存的请求。

### 1.3 堆管理器的目标

- 块内存管理
- 几种数据结构
- 一些安全机制
- 动态分配和回收
- 提高利用率
- 减少碎片化

### 1.4 Linux 堆分配器

目前 Linux 标准发行版中使用的堆分配器是 glibc 中的堆分配器：**ptmalloc2**。ptmalloc2 主要是通过 `malloc`/`free` 函数来分配和释放内存块。

## 2. 堆数据结构

### 2.1 Chunk（内存块）

在程序的执行过程中，我们称由 `malloc` 申请的内存为 **chunk**。这块内存在 ptmalloc 内部用 `malloc_chunk` 结构体来表示。当程序申请的 chunk 被 `free` 后，会被加入到相应的空闲管理列表中。

非常有意思的是，无论一个 chunk 的大小如何，处于分配状态还是释放状态，它们都使用一个统一的结构。虽然它们使用了同一个数据结构，但是根据是否被释放，它们的表现形式会有所不同。

#### malloc_chunk 结构体定义

```c
struct malloc_chunk {
    /* #define INTERNAL_SIZE_T size_t */
    INTERNAL_SIZE_T  prev_size;  /* Size of previous chunk (if free). */
    INTERNAL_SIZE_T  size;       /* Size in bytes, including overhead. */
    struct malloc_chunk* fd;     /* 这两个指针只在 free chunk 中存在 */
    struct malloc_chunk* bk;

    /* Only used for large blocks: pointer to next larger size. */
    struct malloc_chunk* fd_nextsize;
    struct malloc_chunk* bk_nextsize;
};
```

**字段说明：**

| 字段 | 说明 |
|------|------|
| `prev_size` | 前一个 chunk 的大小（仅在前一个 chunk 为 free 时有意义） |
| `size` | 当前 chunk 的大小（包含堆头部），单位为字节 |
| `fd` | 指向 freelist 中的下一个块（仅 free chunk 使用） |
| `bk` | 指向 freelist 中的上一个块（仅 free chunk 使用） |
| `fd_nextsize` | 指向 freelist 中下一个 large chunk（仅 large bin 使用） |
| `bk_nextsize` | 指向 freelist 中上一个 large chunk（仅 large bin 使用） |

---

### 2.2 Allocated Chunk（已分配块）

```
chunk ──→ ──────────────────────────────────────┐
          │  If previous chunk is free, this field │
          │  contains size of previous chunk,      │
          │  else user data.                       │
          ├──────────────────┬───┬───┬───┤
          │  This chunk size │ N │ M │ P │
mem ──→   ├──────────────────┴───┴───┴───┤
          │                                │
          │          User data             │
          │                                │
          ├────────────────────────────────┤
ext chunk─→│  Previous size field contains  │
          │  user data since its previous  │
          │  chunk is allocated.           │
          └────────────────────────────────
```

#### 关键字段详解

**Chunk size 字段：**
- 包含了堆头部
- 由于对齐问题，size 的**低三位恒为 0**，用作标志位：
  - **N（NON_MAIN_ARENA）**：当 chunk 属于一个 thread arena 时，设置此位
  - **M（IS_MMAPPED）**：当 chunk 是 mmap 创建的，设置此位
  - **P（PREV_INUSE）**：前一个 chunk 被分配时，设置此位

**Prev_size 字段：**
- 表示前一个相邻块的大小
- 前一个 chunk 为 **free** 的时候有意义
- 前一个 chunk 为 **allocated** 时，该区域作为用户空间使用

---

### 2.3 Free Chunk（空闲块）

```
chunk ──→ ┌──────────────────────────────────────┐
          │  User data of previous chunk since     │
          │  previous chunk is allocated.          │
          ├──────────────────┬───┬───┬───┤
          │  This chunk size │ N │ M │ P │
mem ──→   ├──────────────────┴───┴───┴───┤
          │  fd - Points to next chunk     │
          │      in the binlist.           │
          ├────────────────────────────────┤
          │  bk - Points to previous chunk │
          │      in the binlist.           │
          ├────────────────────────────────┤
          │                                │
          │         Unused Space           │
          │                                │
          ├────────────────────────────────┤
next chunk─→│  Previous size field contains  │
          │  its previous chunk's size     │
          │  since previous chunk is free. │
          └────────────────────────────────┘
```

#### 空闲块指针字段

| 字段 | 说明 |
|------|------|
| `fd` | 指向 freelist 中的**下一个**块 |
| `bk` | 指向 freelist 中的**上一个**块 |
| `fd_nextsize` | 指向 freelist 中下一个 **large chunk** |
| `bk_nextsize` | 指向 freelist 中上一个 **large chunk** |

> **注意**：`nextsize` 只在 **large bin** 链表中使用。

## 3. malloc 机制

### 3.1 Bins 概述

ptmalloc 将空闲的 chunk 组织成不同的 **Bins**（链表），以便快速查找和分配。

#### Bins 分类

```
─────────────────────────────────────────────────────────────┐
│                      Arena                                  │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐   │
│  │           Freelist Data Structure (bins)             │   │
│  │                                                      │   │
│  │  ┌──────────────┐  ┌──────────────────────────────┐  │   │
│  │  │ 16~64 B      │  │  Unsorted bins[1]            │  │   │
│  │  │ fastbinY[10] │  │                              │  │   │
│  │  │    FILO      │  │  ──────────┐  ┌──────────┐  │  │   │
│  │  └──────────────┘  │  │ <512 B   │  │ ≥512 B   │  │  │   │
│  │                    │  │ Small    │  │ Large    │  │  │   │
│  │  ┌──────────────┐  │  │ bins[2~63]│ │ bins[64~126]│ │  │   │
│  │  │  bins[126]   │  │  └──────────  └──────────┘  │  │   │
│  │  │    FIFO      │  └──────────────────────────────┘  │   │
│  │  └──────────────┘                                    │   │
│  │                                                      │   │
│  │  ┌──────────────┐                                    │   │
│  │  │  top chunk   │  (唯一)                             │   │
│  │  └──────────────┘                                    │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

#### 各 Bin 类型总结

| Bin 类型 | 链表结构 | 分配策略 | chunk 大小范围 |
|----------|----------|----------|----------------|
| **Fastbin** | 单链表 | FILO（后进先出） | 0x20 ~ 0x80（64bit），0x10 递增 |
| **Small bin** | 双向循环链表 | FIFO（先进先出） | 0x20 ~ 0x400（64bit），0x10 递增 |
| **Unsorted bin** | 双向循环链表 | FIFO | 大小不一 |
| **Large bin** | 双向循环链表 | FIFO | ≥ 512 B |
| **Tcache bin** | 单链表 | FILO | 线程缓存 |

---

### 3.2 Fastbin

大多数程序经常会申请以及释放一些比较小的内存块。如果将一些较小的 chunk 释放之后发现存在与之相邻的空闲的 chunk 并将它们进行合并，那么当下一次再次申请相应大小的 chunk 时，就需要对 chunk 进行分割，这样就大大降低了堆的利用效率。因为我们把大部分时间花在了合并、分割以及中间检查的过程中。因此，ptmalloc 中专门设计了 **fast bin**，对应的变量就是 `malloc_state` 中的 `fastbinsY`。

#### Fastbin 特点

- **管理 free fast bin chunk** — 单链表结构 — **FILO**（后进先出）
- 仍被标记为 **prev_inuse 位**，**不会进行合并**
- 总共有 **10 个 bins**，每个 bin 中 chunk 大小一样，范围：`0x20 ~ 0x80`（64bit），`0x10` 递增
- 实际上有 **3 个并不使用**

#### Fastbin 链表结构示意

```
fastbinsY:  ptr0    ptr1    ...    ptr2     0       0       0
             │       │              │
             ▼       ▼              ▼
          ┌──────┐ ──────┐     ┌──────┐     ┌──────┐
          │pre   │ │pre   │     │pre   │────→│pre   │
          │size  │ │size  │     │size  │     │size  │
          │0x21  │ │0x31  │     │0x81  │     │0x81  │
          │fd=null│ │fd=null│   │fd=ptr3│    │fd=null│
          └──────┘ └──────┘     ──────┘     └──────┘
```

> **关键点**：Fastbin 中的 chunk 虽然已被 free，但其 `prev_inuse` 位仍然被设置为 1，因此 ptmalloc 认为它前面的 chunk 仍处于分配状态，**不会触发合并操作**。

---

### 3.3 Small Bin

small bins 中一共有 **62 个循环双向链表**，每个链表中存储的 chunk 大小都一致。比如对于 32 位系统来说，下标 2 对应的双向链表中存储的 chunk 大小为均为 16 字节。每个链表都有链表头结点，这样可以方便对于链表内部结点的管理。此外，small bins 中每个 bin 对应的链表采用 **FIFO** 的规则，所以同一个链表中先被释放的 chunk 会先被分配出去。

#### Small Bin 特点

- **管理 small chunk** — 双向循环链表 — **FIFO**（先进先出）
- 共 **62 个 bins**，每个 bin 中 chunk 大小一样
- 范围：`0x20 ~ 0x400`（64bit），`0x10` 递增

---

### 3.4 Unsorted Bin

unsorted bin 可以视为空闲 chunk **回归其所属 bin 之前的缓冲区**。

unsorted bin 中的空闲 chunk 处于**乱序状态**，主要有两个来源：

1. 当一个较大的 chunk 被**分割成两半**后，如果剩下的部分大于 MINSIZE，就会被放到 unsorted bin 中。
2. 释放一个**不属于 fast bin** 的 chunk，并且该 chunk **不和 top chunk 紧邻**时，该 chunk 会被首先放到 unsorted bin 中。

#### Unsorted Bin 特点

- **管理 unsorted chunk** — 双向循环链表 — **FIFO**
- **只有一个 bin**，bin 中 chunk 大小**不一样**
- 除 fast chunk 之外的 chunk 被 free 时都会**先进入 unsorted bin**，类似于缓存

## 4. free 机制

### 4.1 free 的基本流程

当调用 `free(ptr)` 释放一个 chunk 时，ptmalloc 会按照以下逻辑处理：

```
free(ptr)
    │
    ├── ptr 为 NULL？ ──→ 直接返回，不做任何操作
    │
    ├── chunk 属于 fastbin 范围？
    │       │
    │       ├── 是 ──→ 插入对应的 fastbin 链表头部（FILO）
    │       │          标记 prev_inuse 位，不合并
    │       │
    │       └── 否 ──→ 进入下一步
    │
    ├── chunk 与 top chunk 相邻？
    │       │
    │       ├── 是 ──→ 与 top chunk 合并，扩大 top chunk
    │       │
    │       └── 否 ──→ 放入 unsorted bin
    │
    └── 检查前后相邻 chunk 是否空闲
            │
            ├── 前一个 chunk 空闲 ──→ 向前合并（unlink）
            ├── 后一个 chunk 空闲 ──→ 向后合并（unlink）
            └── 合并后放入 unsorted bin
```

### 4.2 合并机制（Consolidation）

当释放的 chunk 不属于 fastbin 时，ptmalloc 会尝试与相邻的空闲 chunk 进行合并，以减少内存碎片：

- **向后合并**：检查当前 chunk 的下一个 chunk 是否空闲（通过检查下一个 chunk 的 `prev_inuse` 位）
- **向前合并**：检查当前 chunk 的 `prev_inuse` 位，如果为 0，说明前一个 chunk 是空闲的，进行向前合并

合并后的 chunk 会被放入 **unsorted bin** 中，等待后续的分类处理。

### 4.3 各 Bin 在 free 时的行为对比

| Bin 类型 | free 时的行为 | 是否合并 |
|----------|--------------|----------|
| **Fastbin** | 直接插入链表头部，标记 prev_inuse | **不合并** |
| **Small/Large bin** | 先放入 unsorted bin，后续分类 | 会合并相邻空闲块 |
| **Unsorted bin** | 本身就是缓冲区，free 后先进入这里 | 会合并相邻空闲块 |
| **Top chunk** | 与相邻释放块合并，扩大自身 | 合并 |

## 附录：关键概念速查表

### Chunk 标志位

| 位 | 名称 | 含义 |
|----|------|------|
| P (bit 0) | PREV_INUSE | 前一个 chunk 是否被分配（1=已分配，0=空闲） |
| M (bit 1) | IS_MMAPPED | chunk 是否由 mmap 创建 |
| N (bit 2) | NON_MAIN_ARENA | chunk 是否属于非主线程 arena |

### 各 Bin 大小范围（64bit 系统）

| Bin 类型 | 大小范围 | 递增步长 | bin 数量 |
|----------|----------|----------|----------|
| Fastbin | 0x20 ~ 0x80 | 0x10 | 10（实际使用 7 个） |
| Small bin | 0x20 ~ 0x400 | 0x10 | 62 |
| Large bin | ≥ 0x200 (512B) | 不等 | 63 |
| Unsorted bin | 大小不一 | — | 1 |

### malloc_chunk 字段使用状态

| 字段 | Allocated Chunk | Free Chunk |
|------|-----------------|------------|
| `prev_size` | 前一个 chunk 为 free 时存储其大小；否则作为用户数据 | 存储前一个 chunk 的大小 |
| `size` | 当前 chunk 大小 + 标志位 | 当前 chunk 大小 + 标志位 |
| `fd` | 用户数据 | 指向 freelist 中下一个块 |
| `bk` | 用户数据 | 指向 freelist 中上一个块 |
| `fd_nextsize` | 用户数据 | 仅 large bin 使用 |
| `bk_nextsize` | 用户数据 | 仅 large bin 使用 |
